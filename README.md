# Aarogya AI – Anisha

## Overview
What Aarogya AI is and the Health Access problem it solves.

## Key Features
- Indian voice with Murf Falcon
- Hindi / Hinglish support
- Safety guardrails
- User memory
- Health-access tools
- Outbound calls
- Human escalation
- Call analytics
- Specialist handoff
- Frontend agent-state UI
